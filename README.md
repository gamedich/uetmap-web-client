# УЭТ Карты — публичный клиент

Исходный код пассажирского веб-интерфейса карты. Рабочий сайт: https://uet-map.ru/

Это клиентский код: ему нужны API и безопасный сервер тайлов. Серверная часть, оперативные данные, HR, ключи и защитная геометрия в этот репозиторий не входят. Репозиторий сам по себе не является готовым серверным развёртыванием. Приложение Android: https://github.com/gamedich/uetmap-passenger

Изменения веб-сайта не выкатываются автоматически из этого репозитория.
